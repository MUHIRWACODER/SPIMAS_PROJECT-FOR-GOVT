# SPIMAS: Smart Public Infrastructure Monitoring & Accountability System

SPIMAS is a web-based platform built to foster public transparency and simplify infrastructure maintenance tracking for government projects. This repository contains the frontend interface tailored for citizens, contractors, and engineers.

---

## 🎨 Key Features

* **Citizen Portal (`citizen.html`):** An intuitive dashboard for citizens to report local public infrastructure issues and track active cases.
* **Contractor Portal (`contractorportal.html`):** A dedicated view for authorized contractors to accept maintenance jobs and update project timelines.
* **Engineering Dashboard (`engineeringdashboard.html`):** An administrative hub for government engineers to oversee reports, assign tasks, and monitor resource efficiency.
* **Responsive Styling (`spamis_styling.css`):** Custom CSS that binds the user interfaces together, ensuring clean typography, accessibility, and smooth, responsive layouts.

---

## 🛠️ Built With

* **HTML5:** Structuring semantic dashboards for three separate user roles.
* **CSS3:** Custom styles emphasizing clean grid layouts, distinct user panels, and modern UI elements.
